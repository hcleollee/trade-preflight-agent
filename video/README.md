# Demo video

`trade-preflight-track-a.mp4` is a 90-second, 1080p Track A submission video assembled from genuine local PASS/BLOCK captures and public Binance MCP evidence.

Rebuild the narration on macOS:

```bash
say -v Samantha -r 150 -f video/narration.txt -o video/narration.aiff
```

The final edit uses FFmpeg to combine the title cards, genuine local PASS/BLOCK captures, narration, and bilingual captions.

The video intentionally excludes authenticated responses, balances, account identifiers, order identifiers, and transaction history.
