## Short project description

Trade Preflight is a permission-scoped risk layer for agentic trading. It reads Binance market data, simulates a proposed order against the live book, applies deterministic account controls, and returns an auditable PASS, WARN, or BLOCK decision. Every executable proposal remains locked behind explicit human confirmation.
